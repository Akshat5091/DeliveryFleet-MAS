Dual-Framework Agent Architecture

1. Hierarchical Manager (Supervisor)

Directs the workflow lifecycle, orchestrates parallel context gathering via ThreadPoolExecutor, and verifies invariants before final mission sign-off.

2. Google ADK Route Planning Agent

Exposes an interoperable AgentCard, receives typed A2AMessage payloads, and computes Pareto-optimal transit routes factoring traffic matrices.

3. CrewAI Dispatch & Exception Agents

CrewDispatchAgent executes multi-criteria driver selection; CrewExceptionAgent dynamically intercepts mid-route failures and performs real-time reroutes.

4. Blackboard Shared Memory State

Single source of truth guarded by `threading.RLock()`. Every state mutation records agent identity, timestamp, and payload for full provenance auditing.
